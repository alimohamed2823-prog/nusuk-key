# مفاتيح نسك — نسخة أولية قابلة للنشر

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية متجاوبة مع الهاتف والكمبيوتر مستوحاة من تسجيل الشاشة المرسل.
- المفتاح المثبت `NG-moe8R4N6` يظهر في أعلى القائمة ولا يختفي.
- نسخ المفتاح أو فتح رابط الإحالة يخفيه محليًا عند هذا الزائر فقط.
- إخفاء المفاتيح محفوظ في المتصفح بعد إغلاقه.
- لصق حتى 1000 مفتاح دفعة واحدة، مع إزالة التكرار والتحقق من صيغة `NG-` + 8 أحرف/أرقام.
- قاعدة بيانات مشتركة عبر Supabase عند ربط بيانات المشروع.
- شاشة إدارة تتطلب حساب مدير، ويمكن للمدير حذف المفاتيح غير المثبتة.

## تشغيل تجريبي
افتح `index.html` في المتصفح. قبل ربط Supabase سيظهر وضع معاينة فقط، ولن تتم مشاركة البيانات بين الزوار.

## تفعيل قاعدة البيانات المشتركة
1. أنشئ مشروعًا مجانيًا في Supabase.
2. افتح SQL Editor والصق محتوى `schema.sql` ثم نفّذه.
3. من Project Settings > API انسخ Project URL و anon/publishable key.
4. ضع القيمتين في `config.js` بدل النصين `PASTE_...`.
5. أنشئ مستخدم مدير من Authentication > Users (بريد وكلمة مرور).
6. انسخ UUID للمستخدم ثم نفّذ في SQL Editor:
   `insert into public.site_admins(user_id) values ('UUID-هنا');`
7. ارفع ملفات المجلد كما هي إلى استضافة صفحات ثابتة مثل Netlify أو Cloudflare Pages أو GitHub Pages.

**مهم:** لا تضع `service_role key` في `config.js` أو أي ملف يصل للمتصفح.

## رابط نسك
زر «فتح في نسك» يستخدم رابط إحالة من الشكل:
`https://services.nusuk.sa/app?p=27&id=NG-XXXXXXXX`
وهذا هو نمط الروابط الذي يستخدم لفتح صفحة الإحالة في تطبيق نسك عندما يكون التطبيق مثبتًا. قد يختلف سلوك الفتح حسب الجهاز وإعدادات الروابط؛ لذلك يوفر الموقع زر نسخ كبديل.

## ملاحظات تشغيلية
- الإضافة العامة مفتوحة، والنسخ المكررة تتجاهلها قاعدة البيانات تلقائيًا.
- الأكواد المضافة تصبح مرئية للجميع فور حفظها. إذا أردت مراجعة كل الإضافات قبل النشر، يجب إضافة جدول انتظار وموافقة مدير قبل إظهارها.
- «المفتاح المستخدم» لا يمكن التحقق منه تلقائيًا من نسك؛ الموقع يسجل فقط أن الزائر ضغط فتح/نسخ، ويخفيه من قائمته الشخصية.
- هذا مشروع مستقل غير تابع لنسك أو لوزارة الحج والعمرة.
